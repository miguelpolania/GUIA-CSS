2.1

Estructura y sintaxis

Una regla CSS tiene tres piezas: el selector (a quién), la propiedad (qué cambio) y el valor (cómo queda). Las propiedades y valores van dentro de llaves { }, se separan con : y cada declaración termina en ;.

h1 {                    /* selector */
    color: crimson;      /* propiedad: valor; */
    font-size: 2rem;
}
selector propiedad valor
Tipos de selectores más usados
  • p · de elemento
  • .caja · de clase
  • #menu · de id
  • * · universal
  • div p · descendiente
  • div > p · hijo directo
  • h1, h2 · agrupados
2.2

Tipos de incorporación

Hay tres maneras de conectar CSS con HTML. Elige según el tamaño del proyecto.

Un archivo .css aparte, enlazado desde el <head>. Es la forma recomendada: se reutiliza en varias páginas.

<!-- index.html -->
<link rel="stylesheet" href="index.css">

/* index.css */
body { background-color: #A2A44C; }

Dentro de una etiqueta <style> en el <head>. Sirve para páginas pequeñas o pruebas rápidas. Esta guía usa CSS externo (css/styles.css).

<head>
    <style>
        p { color: teal; }
    </style>
</head>

Con el atributo style directamente en la etiqueta. Tiene mucha fuerza (especificidad), pero es difícil de mantener.

<p style="color: teal; font-weight: bold;">Texto</p>
TipoDónde vaVentajaDesventaja
ExternoArchivo .cssReutilizable y ordenadoUna petición extra
Interno<style>Todo en un archivoNo se comparte entre páginas
En líneastyle=""Prioridad alta, rápidoDesordenado, difícil de mantener
2.3

Identación, herencias y comentarios

CSS no exige identación, pero ordenarlo te ahorra errores. Una declaración por línea y sangría de 4 espacios.

Difícil de leer 
.caja{color:red;height:100px;background:blue}
Ordenado 
.caja {
    color: red;
    height: 100px;
    background: blue;
}

Algunas propiedades (color, font-family, font-size, line-height) pasan a los hijos solas. Otras (border, margin, padding, background) no. Puedes forzarlas con inherit.

Soy el padre: color morado y fuente Georgia.

Soy un hijo sin reglas propias: heredo todo.

Soy un hijo con reglas propias: color verde y otra fuente.

.padre { color: #6f42c1; font-family: Georgia; }
.hijo  { border: inherit; }  /* forzar herencia */

Se escriben entre /* */, pueden ocupar varias líneas y el navegador los ignora. Úsalos para explicar o para desactivar una línea sin borrarla. Ojo: // no funciona en CSS.

/* ===== Cabecera ===== */
.caja1 {
    height: 30px;
    /* background-color: red;  ← desactivada */
}

2.6
Media queries

        
Son condiciones que aplican reglas CSS solo cuando se cumple algo, normalmente el ancho de pantalla. Con min-width piensas "de este tamaño hacia arriba" (mobile first). Con max-width, "de este tamaño hacia abajo".

        

            


.caja { height: 100px; }   /* móvil */

@media (min-width: 768px) {
    .caja { height: 150px; }
}
@media (min-width: 992px) {
    .caja { height: 200px; }
}
@media (max-width: 575.98px) {
    .caja { display: none; }
}

            

            

                

                

                    
Ancho actual de la ventana0 px

                    

                    
Redimensiona la ventana y mira cómo cambian el color y el texto de la caja.

                

            

        

        
 Otras condiciones útiles: (orientation: landscape), (prefers-color-scheme: dark) y print para impresión.

    


    
    

        
2.7
Pseudo-elementos

        
Se escriben con dos dos puntos (::). Estilizan una parte de un elemento o crean contenido extra sin tocar el HTML. Para ::before y ::after la propiedad content es obligatoria.

        

            

                
::before y ::after

                
Texto con estrella antes

                
Texto con check después


p::before { content: "★ "; }
p::after  { content: " ✔"; }

            

            

                
::first-letter

                
CSS permite darle estilo a la primera letra de un párrafo para lograr efectos editoriales, como las revistas.


p::first-letter { font-size: 3rem; float: left; }

            

            

                
::first-line

                
La primera línea de este párrafo cambia de estilo y, si reduces la ventana, el efecto se adapta a lo que quepa en esa primera línea.


p::first-line { text-transform: uppercase; }

            

            

                
::selection y ::placeholder

                
Selecciona este texto con el mouse y verás el color amarillo.

                

p::selection { background: #ffc107; }
input::placeholder { color: red; }

            

        

        

            
Ejemplo real: cinta decorativa

            
La cinta roja "NUEVO" es solo un ::before con position: absolute y transform: rotate(45deg). No existe en el HTML.

        

    


    
    

        
2.8
Pseudo-clases

        
Se escriben con un solo dos puntos (:). Aplican estilo según el estado del elemento o su posición entre hermanos.

        

            

                
Estados: :hover :active :focus-visible :disabled

                

                    
                    
                

                
Prueba también navegar con la tecla Tab para ver el :focus-visible.


.btn:hover    { background: cyan; }
.btn:active   { transform: scale(.95); }
.btn:disabled { background: gray; }

            

            

                
Posición: :first-child :last-child :nth-child()

                
    
                    
  • Primero (first-child)
    • 
                    
  • Segundo (even)
    • 
                    
  • Tercero
    • 
                    
  • Cuarto (even)
    • 
                    
  • Último (last-child)
    • 
                


li:first-child      { color: green; }
li:nth-child(even) { background: #eee; }

            

            

                
Formularios: :checked :focus :valid :invalid

                

                
                

input:checked + label { text-decoration: line-through; }
input:invalid { border-color: red; }

            

            

                
Útiles para lógica: :not() :is() :has()


/* todos los li menos el último */
li:not(:last-child) { border-bottom: 1px solid; }

/* agrupar selectores */
:is(h1, h2, h3) { font-family: Georgia; }

/* tarjeta que contiene una imagen */
.card:has(img) { padding: 0; }

                
Regla útil: pseudo-clase = estado (:), pseudo-elemento = parte (::).

            

        

    


    
    

        
2.9
Z-index

        
z-index controla qué elemento queda encima cuando se superponen. Un número mayor queda arriba. Solo funciona en elementos con position distinto de static (relative, absolute, fixed, sticky) y en hijos de flex o grid.

        

            

                

                    
A

                    
B

                    
C

                

            

            

                

                    
                    
                    
                    
                    
                    
                

            

        


.caja {
    position: absolute;   /* sin esto, z-index no hace nada */
    z-index: 10;
}

        

            
Contexto de apilamiento. Un hijo nunca puede salir del contexto de su padre: si el padre tiene z-index: 1, el hijo con z-index: 9999 sigue quedando debajo de un elemento con z-index: 2 fuera del padre.

            
Escala de Bootstrap. Dropdown 1000, sticky 1020, fixed 1030, offcanvas 1045, modal 1055, popover 1070, tooltip 1080, toast 1090. Por eso la navbar fija queda sobre el contenido. Y la etiqueta de breakpoint de abajo a la derecha también usa z-index.
